Mobile-First Design Spec

The reference for how the noprofits.org site is designed and built — starting from the smallest screen and progressively enhancing up. Every layout, type size, and interaction is defined at the mobile base first; larger breakpoints only add space and columns, never new behavior.

Core principles

Design the phone firstAuthor base styles for ≤599px, then layer min-width media queries upward.
One column by defaultEvery multi-column grid collapses to a single stacked column on mobile.
Thumb-friendly targetsAll tap targets are ≥44×44px with comfortable spacing between them.
Performance is a featureStatic Astro output, responsive images, system-fast fonts — fast on cellular.

Touch & interaction

  • Minimum tap target 44×44px; primary buttons are full-width on mobile with ≥48px height.
  • At least 8px of clear space between adjacent tappable elements.
  • Phone numbers are tel: links; the header number stays one-tap reachable.
  • Focus states are visible (2px accent ring) for keyboard and switch users.
  • No hover-only actions — all functionality works on tap.

How each section reflows

Header / navInline links collapse to a hamburger menu below 900px. Wordmark + phone link stay visible; "Start your site" CTA becomes a full-width button inside the open menu.
HeroTwo-column split stacks: headline + CTAs first, then the "Get your site" form card below it full-width. H1 drops to 32px.
Value pillars3-up row becomes a single stacked column; left dividers are removed in favor of vertical spacing.
How it works4 step cards: 1-up on mobile, 2-up at Small, 4-up at Medium+.
What you get6-item grid: 1-up → 2-up → 3-up. Outer panel padding drops from 56px to 24px.
Cost comparisonTwo price cards stack vertically; the noprofits.org card stays second so it reads as the conclusion.
Guides3 guide cards: 1-up → 2-up → 3-up. Covers keep a 16:9 ratio.
Contact formIntro column stacks above the form. Paired fields (email/phone) go full-width single-column on mobile.
FooterBrand block and link groups stack vertically; bottom legal row wraps.

Forms on mobile

  • Inputs are full-width, ≥48px tall, 16px text (prevents iOS zoom-on-focus).
  • Correct input types trigger the right keyboard: email, tel, text.
  • Required fields (name, organization, email, phone) marked with an accent asterisk and native validation.
  • Submit button is full-width and fixed in tab order after the last field.
  • On submit, an inline success state replaces the form — no page reload, submission logged to Google Sheets + emailed.

Imagery, performance & SEO

  • Responsive images via Astro's image pipeline — srcset + width/height to reserve space and avoid layout shift.
  • Hero and above-the-fold images eager-loaded; everything below lazy-loaded.
  • Fonts loaded with display=swap and preconnect; text renders immediately.
  • Single semantic <h1> per page, descriptive meta + Open Graph tags, sitemap, and fast static delivery for strong mobile SEO.
  • Target: Lighthouse mobile performance ≥90, no cumulative layout shift.
